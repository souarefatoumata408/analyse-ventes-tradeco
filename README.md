# 📊 Analyse des Ventes TradeCo Dashboard Excel Interactif 
Projet d'analyse de données réalisé dans le cadre de la formation **Analyse de Données Excel** by ADN. 
## 📊 Objectif Nettoyer, analyser et visualiser 2 000+ transactions commerciales pour produire un tableau de bord interactif permettant de piloter les ventes de l'entreprise TradeCo. 
## 📊 Compétences démontrées 
- Nettoyage de données (doublons, types, valeurs manquantes)
- Formules avancées : NB.SI.ENS, SOMME.SI.ENS, RECHERCHEV, INDEX/EQUIV
- Tableaux Croisés Dynamiques + Segments interactifs
- Dashboard professionnel avec KPIs visuels
